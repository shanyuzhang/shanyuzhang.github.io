# shanyuzhang.com

Personal academic website of Shanyu Zhang, live at <https://shanyuzhang.com>.

Built with [Jekyll](https://jekyllrb.com/) on the [al-folio](https://github.com/alshedivat/al-folio) theme and deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

## Editing

- Homepage content (bio, news, publications, education): `_pages/about.md`
- Site settings: `_config.yml`
- Social links and email: `_data/socials.yml`

## Local preview

```bash
docker compose up
```

Then open <http://localhost:8080>.
